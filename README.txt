# Jahnavi Battu — Portfolio redesign

## Files
- `index.html` — complete semantic page structure
- `styles.css` — responsive dark editorial / AI-lab design
- `script.js` — mobile navigation, scroll progress, reveal animations, project hover tilt

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your real professional email.
2. Replace the three placeholder experience cards with exact employer names, job titles, dates, and verified accomplishments from your resume.
3. Replace each project link currently pointing to your GitHub profile with the specific repository URL.
4. Add your resume PDF to the repository (for example, `assets/Jahnavi_Battu_Resume.pdf`) and add a resume download link if desired.
5. Confirm all listed technologies reflect your actual experience.

## GitHub Pages
Keep `index.html`, `styles.css`, and `script.js` in the repository root (or update the relative paths if you use a subfolder). Commit and push to the branch/folder configured in GitHub Pages.

The page uses Google Fonts; if fonts cannot load, it falls back to system sans-serif.
